# 报告模板

三类报告共用同一套骨架：**结论先行 → 口径声明 → 逐维依据 → 硬门槛核查 → 待补证 → 附录**。

选择对应版本：

- [A. 单 ASIN 竞品调研](#a-单-asin-竞品调研)
- [B. 类目扫描与替代方向](#b-类目扫描与替代方向)
- [C. 主题／产品线选题](#c-主题产品线选题)

---

## 通用规范

**封面必含**：报告名、对象、依据的方法论版本、数据源、数据窗口（销量窗口 / 关键词窗口分开写）、日期。

**执行摘要必含**：四状态结论、一句话判断、三重硬门槛核查结果（通过/不通过/待补证）。

**全文禁止**：
- 没有数据来源的结论
- "建议谨慎考虑""有一定风险"这类无法执行的判断
- 把工具估算写成精确值
- 把缺失数据推断成"没有风险"

**每张表都要能回答一个问题**。回答不了的表删掉。

## A. 单 ASIN 竞品调研

```
# [ASIN] 选品调研报告
[品牌 + 标题 + 规格] · 含 N 个竞品横向对比

## 执行摘要
- 决策状态：淘汰 / 待补证 / 允许测款 / 允许放量
- 硬门槛：毛利 __（通过/不通过）· 安全 __（待补证/通过）· 侵权 __（未发现/待检索）
- 一句话结论：__

## 一、调研概览与数据口径
1.1 调研对象与范围（ASIN、类目、categoryId、类目路径、ASIN 数）
1.2 数据窗口（销量 / 关键词 / 趋势分别注明）
1.3 数据源与可信度（A/B/C 分级说明）

## 二、五步决策顺序逐项结果
（五步逐一给结论，附依据与可信度）

## 三、目标产品画像
（形态、材质、尺寸重量、包装、FBA 费、售价、变体结构）

## 四、市场需求与容量
4.1 类目规模与增长
4.2 关键词需求（大词 / 精准词 / 长尾词分层）
4.3 季节性

## 五、竞争格局（N 个竞品对比）
（表格必含：ASIN、品牌、标题、售价、件数、FBA、广告前毛利率、月销、评分数、星级、上架天数、产品形态、自然位占比）

## 六、变体调研（父体下 X 子体，单独成表）
（父 ASIN、子 ASIN、变体主题、价格、评分数归属、月销、库存）

## 七、关键词需求与流量结构
7.1 核心词与购买意图
7.2 搜索量 / 难度 / CPC / CVR
7.3 流量来源结构（自然位 vs 广告位）
7.4 广告可行性（可承受 CPC 倒推）

## 八、利润与成本测算（核心）
8.1 成本明细（逐项）
8.2 三层利润
8.3 价格下限与销量加权价对比
8.4 降价压力测试（-10% / -20%）
8.5 保本 ACOS 与目标 ACOS

## 九、安全与合规核查
（预期年龄、适用规则、所需证明、未解决事项）

## 十、差异化与评论证据
（评论原文 → 场景 → 问题 → 变体 → 出现次数 → 改进方式 → 增加成本 → 验证方法）

## 十一、结论与待补证清单
11.1 四状态判定
11.2 关键缺失（阻止测款）
11.3 辅助缺失（不阻止）
11.4 若继续，下一步动作

## 附录：数据来源与可信度
```

## B. 类目扫描与替代方向

```
# [类目名] 类目调研与替代方向

## 执行摘要
- 类目结论：值得做 / 不值得做
- 替代方向：N 个候选 + 明确否决项
- 一句话结论：__

## 一、调研范围与数据口径

## 二、类目全景
2.1 规模与增长
2.2 品牌结构（品牌数、TOP10 占比）
2.3 细分节点清单（ASIN 数 / 第一品牌份额 / 价格带）

## 三、结构性诊断
3.1 价格分布（销量在哪个价格带）
3.2 价格下限 vs 加权成交价
3.3 新品存活实证（近 N 天月销破 X 的新品数量与形态）
→ 结论：这个类目是"竞争激烈"还是"结构性亏损"

## 四、候选方向筛选与五步决策
（每个方向单独走五步）

## 五、利润测算对照
（所有候选方向的完整成本表，横向对比毛利率与价格下限）

## 六、测款执行模板
（预算上限、最大亏损、观察期限、有效点击/订单要求、停止条件、补货条件）

## 七、风险、待补证与下一步

## 附录：数据来源与关键原表
```

## C. 主题／产品线选题

```
# [主题／产品线] 选题报告
以 [参照卖家/产品线] 为参照的 N 个主题可做性排序

## 结论摘要
- 分层结果：A 可做 X 个 / B 待补证 X 个 / C 观察 X 个 / D 淘汰 X 个
- 一句话结论：__

## 第一部分 参照对象拆解
1.1 产品线全景（ASIN 数、价格带、FBA 分布）
1.2 销售结构的真相（月销、营收、前 N 个 SKU 占比）
1.3 结构性盲区（他缺什么）
1.4 他自己的毛利（用价格下限回算，看多少 SKU 真达标）

## 第二部分 判断规则
2.1 从"选品判断"到"主题筛选"
2.2 价格下限（FBA 档位实测表）
2.3 六个筛选指标与口径
2.4 数据边界（必须说明的限制）

## 第三部分 全量对比
（一张表装下所有候选：在售 ASIN、TOP10 销量、价格区间、加权价、过门槛占比、
 评论壁垒、近 420 天新品数、广告依赖、大词搜索量、CPC、综合分）

## 第四部分 分层结论
4.1 A 类：可做（允许测款）—— 逐个给产品形态、定价、包装厚度、测款参数
4.2 B 类：待补证 —— 缺什么、怎么补
4.3 C 类：观察，不进 —— 什么条件下重看
4.4 D 类：淘汰 —— 命中哪条硬门槛

## 第五部分 反直觉发现
（3 条以内，每条都要有数据支撑）

## 第六部分 执行建议
6.1 90 天推进顺序
6.2 测款参数（按模板填满数字）
6.3 必须提前确认的事（合规、供应链、专利）

## 附录 A 数据口径与来源
## 附录 B 价格下限计算表
```

## 测款参数表（三类报告共用）

测款前必须填满，缺一项即视为未准备好：

| 必填项 | 内容 |
|---|---|
| 预算上限 | $____ 本次测款最多投入 |
| 最大亏损 | $____ 触发即停 |
| 观察期限 | ____ 天（观察节点，非判决期限） |
| 有效点击要求 | ≥____ 次（注明广告类型与位置） |
| 有效订单要求 | ≥____ 单（注明样本量与流量来源） |
| 停止条件 | 亏损达 $X / 点击 Y 次仍 0 单 / 退货率高于 Z% |
| 补货条件 | 毛利达标、退货低于 X%、日销稳定 Y 天 |

## 数据可信度标注方式

每个关键数据点后加标注：

- `（A）` 已核实：官方费率、真实成交、评论原文、可查证文件
- `（B）` 工具估算：第三方销量/CPC/流量，需注明工具与口径
- `（C）` 缺失待补：显式标注"待补证"

示例：`目标 ASIN 近 30 天销量 15,419 单（B，工具估算，档位值）`
