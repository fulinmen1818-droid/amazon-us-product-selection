## 亚马逊美国站选品判断方案

## 一、方案总则

### 1.1 方案目的与定位

本方案用于在**产品上线前**，用数据驱动的方式系统性筛掉高风险、低利润、侵权高危、有安全隐患的品类，锁定「有真实需求、竞争可切入、毛利达标、合规且安全可售」的单品。

**本方案的定位必须明确**：六维框架是一份**调研提纲与候选排序工具**，而不是采购判决器。它回答「应该查什么、怎么查、怎么横向比较」，但**是否下单采购，只能由四个决策状态决定**（见 1.2），而决策状态的依据是「硬门槛 + 证据可信度」，不是分数和固定阈值。

核心逻辑：选品失误的代价（滞销、封号、冻结资金、安全事故）远大于选品时间成本，**宁可慢、不可错**；数据缺失时，宁可标「待补证」，也不得推断成「没有需求」或「没有风险」。

### 1.2 判断口径：四状态决策

任何一款待评估竞品，调研结束后落到以下**四种状态之一**：

| 状态 | 触发条件 | 后续动作 |
|------|---------|---------|
| **淘汰** | 已确认无法满足硬门槛（真实成本下广告前毛利 <30% 且无法改善；确认侵权；**存在未解决的严重伤害风险**） | 放弃，记录原因 |
| **待补证** | 关键数据缺失（材料安全、核心成本、权利风险、包装档位等未核清） | 先补齐证据，暂不下采购结论 |
| **允许测款** | 硬门槛通过，但售价接受度、转化率、评论痛点等仍需真实成交验证 | 小批量试销，设试错预算与停止条件 |
| **允许放量** | 已有真实成交、利润、质量、退货、现金需求数据支持 | 按补货周期与现金需求追加订单 |

**打分（六维评分）只用于给候选产品排序**，不替代上面的采购判断。22 分与 21 分不应凭主观印象区分「做与不做」，分数只回答「在可做的候选里，先做哪个」。

### 1.3 决策顺序（五步，固定执行）

| 顺序 | 判断内容 | 结果 |
|------|---------|------|
| **第一步** | 安全、禁售、权利及必要材料依据 | 未解决关键问题 → 待补证或淘汰 |
| **第二步** | 有真实需求和可切入的细分机会 | 有依据才继续；低评价本身不够 |
| **第三步** | 在有依据的售价下，广告前毛利 ≥30%，广告获客有可行空间 | 通过后允许测款 |
| **第四步** | 明确差异化、样品验收、试错预算与停止条件 | 执行小批量验证 |
| **第五步** | 实际成交、利润、质量、退货及现金需求通过验证 | 才允许放量 |

> **允许放量必须由实际经营数据触发**，任何竞品数据、工具估算或规则推断都不能直接触发放量。

### 1.4 数据可信度分级

每个数据点都必须标注可信度，缺失不得默认为「中等分」或「低分」：

- **A 级（已核实）**：官方费率、真实成交数据、原始评论原文、可查证的证书/专利文件。
- **B 级（工具估算）**：第三方工具估算的销量、CPC、流量；需注明工具与估算口径。
- **C 级（缺失）**：未取得的数据，显式标记「待补证」，不得推断成「无需求 / 无风险 / 无竞争」。

**关键原则：原始资料真实，不代表据此作出的判断已经证实。**

- 原始评论只能证明「某位买家报告过这个问题」，**不能直接证明普遍缺陷**。
- 官方费表可信，但**选错包装档位，测算仍会错**。
- 证书可查询，不代表它**覆盖您的具体材料、工厂和使用方式**。
- 亚马逊「2K+ 购买」是**展示档位，不是精确销量**。

### 1.5 关键缺失与辅助缺失（决定是否阻止测款）

数据缺失不能一刀切「都卡住」，要区分级别：

| 缺失级别 | 典型项 | 处理 |
|---------|--------|------|
| **关键缺失（阻止采购 / 测款）** | 材料安全、核心成本、包装档位、权利状态、必要认证 | 必须补齐，未核清 → 待补证，不得进入测款 |
| **辅助缺失（不自动阻止测款）** | 完整 5 年趋势、精确销量、留评率 | 标记「待补证」即可，不自动阻断测款 |

### 1.6 数据源体系

- **亚马逊原生**：商机探测器（Product Opportunity Explorer）、品牌分析（ABA）、AI 市场分析、FBA 计算器、官方费率表。
- **第三方工具**：卖家精灵、Helium 10、Jungle Scout、Keepa、Sorftime（销量估算、关键词挖掘、竞品反查、历史曲线）。
- **西柚找词 MCP（xiyou-insight）**：类目洞察、关键词机会、ASIN 反查、竞品广告分析、销量与流量趋势，作为竞品调研主力数据源。

## 二、口径统一（先定义，后执行）

在执行六维调研之前，必须先统一以下口径，否则不同产品之间的分数与结论不可比、不可复核。

### 2.1 利润口径（硬门槛）

**统一公式**：

> **广告前毛利 = 实收销售收入 − 采购成本 − 包装 − 头程及关税 − 销售佣金 − FBA 配送费 − 入仓仓储 − 退货损耗 − 其他变动费用**

> **广告前毛利率 = 广告前毛利 ÷ 实收销售收入**

> **广告后贡献利润 = 广告前毛利 − 广告花费**

> **经营净利润 = 广告后贡献利润 − 固定运营费用（人工、订阅、设计、测款分摊等）**

**硬门槛**：**广告前毛利率 ≥ 30%**。低于 30% 的产品，必须先「重新设计 / 降成本」，仍无法达到即淘汰；不设「底线 15%」的放行通道。

**折扣处理规则**：折扣若已体现在「实收销售收入」里，就**不得重复扣减**；测算时必须在模板中写明折扣口径。

**售价依据与压力测算（新增）**：毛利不能只用「自己希望卖到的价格」算。每个产品必须同时测算：

- **目标售价**：计划销售价（含优惠券 / 秒杀预期）。
- **市场可比售价**：同类竞品当前实际成交价区间。
- **降价情景**：下调 10% / 20% 后毛利是否仍 ≥30%。

**溢价规则**：若目标售价高于市场可比价，必须有**产品价值依据**（功能增量、材质、配置），并标注「待验证」。无依据的溢价不得作为毛利测算基础。

**单件净利分档**（不再一刀切 $5–10）：

| 客单档 | 价格参考 | 单件净利目标 | 附加判断 |
|--------|---------|-------------|---------|
| 低客单 | < $15 | $2–3 即可，但必须高周转、低广告依赖 | 重点看利润率与资金周转，而非绝对额 |
| 常规 | $15–50 | $5–8 | 兼顾利润率与单件额 |
| 高客单 | > $50 | $10+ | 关注资金占用与周转天数 |

### 2.2 广告口径（ACOS / TACOS）

- **保本 ACOS = 广告前利润率**：这是「广告订单刚好不亏」的临界点，是**上限**，不是日常投放目标。
- **目标 ACOS**：按「广告后仍需贡献正利润」倒推，通常显著低于保本 ACOS。
- **TACOS = 广告花费 ÷ 总销售额**：衡量广告对整体生意的拖累程度，与 ACOS 一起看。

**关键结论（防止误用）**：若某产品广告前毛利率为 30%，而广告订单的 ACOS 达到 35%，在口径一致的前提下，**这部分广告订单已经亏损**。因此「ACOS < 35% 就放大」作为统一规则是**不合理**的，ACOS 门槛必须由每个产品的毛利倒推。

### 2.3 ROI 口径

**单批投入回报率 = 单批净利 ÷ 单批总投入（采购 + 头程 + 广告 + 仓储）**，必须注明计算周期（单批生命周期，还是年化资金回报）。不得只写「ROI > 100%」而不定义分母与时间范围。

### 2.4 选品池分层（取消「一套阈值适用所有类目」）

不同产品形态不能用同一套「单件利润 / 首单数量 / 广告成本」门槛。先归池，再按池内基准比较：

| 选品池 | 典型品类 | 特征 | 池内判断重点 |
|--------|---------|------|-------------|
| **A 池：低客单轻小件** | 派对用品、贴纸、装饰小件 | 单价低、重量轻、靠多变体与周转 | 周转速度、广告成本占比、多变体矩阵 |
| **B 池：常规标品** | 家居日用、办公、配件 | $15–50 主流区间 | 六维均衡，通用基准适用 |
| **C 池：高客单大件** | 车载桌、花毯、家具 | 单价高、重量大、资金要求高 | 差异化深度、配送费与损坏率、资金占用 |

以下所有「参考区间」均为**初筛参考值**，仅用于提示「需要重点看什么」，不作为跨类目的通用判决。

### 2.5 产品安全硬门槛（最重要，独立于毛利与侵权）

**判断标准**：在「预期使用 + 合理可预见的误用」下，是否存在**未解决的严重伤害风险**，包括但不限于：误食 / 窒息（小件脱落）、尖锐件、易燃、化学危害、电击、烫伤等。

**处理规则**：

- **未核清**（材料安全、结构、小件脱落风险不明）→ **待补证**，不得进入测款。
- **已确认存在严重伤害风险**，且**无法通过设计改善**（如改用大尺寸、加安全结构、换材质）→ **淘汰**。

**执行原则**：安全结论**不需要等到出现差评或事故才考虑**。低评价、销量好、毛利达标，都不能抵消「直接放在奶油上可能被误食」这类未解决风险。

> **检验案例（亚克力蛋糕宝石）**：即便低评、销量好、毛利达标，若产品为小尺寸装饰件，直接放在奶油上存在误食风险且未解决，就**不应被规则放行**，应判「待补证」或「淘汰」。

## 三、六维调研框架（调研提纲，非判决器）

每个维度回答「要调研什么问题、采集哪些字段、怎么判断」，并给出分池参考区间。**任何一条参考区间都不构成一票否决，除非它对应 2.1 硬门槛、2.5 安全门槛或明确侵权。**

### 维度一：市场需求与容量

**要回答的问题**：需求是否真实、持续、够大？是长期刚需还是短期爆发？需求是否分散在多个长尾词？

**必采字段**：
- 核心词 + 长尾词的搜索量（注明统计周期与来源，**不能把 ABA 排名当搜索量**）。
- 类目月销量 / GMV 趋势（近 3 年整体方向）。
- 季节性：峰值月份、淡季长度、是否逐年重复。
- 需求是否集中在单一主词，还是分散在多个长尾词（细分需求可能靠多个长尾词，单一主词小不代表没市场）。

**分池参考**：主词月搜索量 ≥3,000 是常规池初筛参考；低客单/细分需求可分散在多个 1,000 以下的长尾词，需汇总判断。

**数据来源**：`get_keyword_info`、`get_category_market_size_trends`、`get_category_seasonality`、`get_asin_bsr_trends`。

**淘汰 / 待补证信号**：市场容量极低到没单量 → 淘汰；需求数据缺失 → 待补证，不得写成「没需求」。

### 维度二：竞争格局与切入机会

**要回答的问题**：流量和坑位是否被垄断？新卖家有没有切入空间？现有竞争者的销量来源是什么？

**必采字段**：
- 首页评论数中位数（低评不代表竞争弱，还需结合销量、价格、品牌、广告投入综合判断）。
- 品牌集中度：第一品牌、前三品牌销量占比（**必须先定义细分市场、观察期、父子体去重、销量来源**，再谈占比）。
- 头部链接的销量构成（自然位 vs 广告位）。
- 核心词 CPC 与竞争难度。
- 是否有 Amazon 自营或超级大卖，且**是否直接覆盖目标需求与价格带**（有自营≠自动红灯）。

**销量 / 流量口径（新增）**：排名、流量估算、销量估算必须**分别记录**，不能互相替代——「自然位 vs 广告位」只能说明流量来源结构，**不能直接证明销量来源**；流量高 ≠ 销量高，转化才是销量的直接前提。

**分池参考**：常规池首页评论中位数 ≤500 为切入参考；低客单池更看重 CPC 与广告集中度；高客单池更看重头部大卖的差异化缺口。

**数据来源**：`get_category_sales_ranking`、`get_category_new_release_opportunity_trends`、`get_keyword_asin_analysis`、`get_keyword_info`、`get_category_brand_market_size`。

**淘汰 / 待补证信号**：头部坑位长期被大卖垄断且无差异化缺口 → 淘汰；品牌集中度数据口径未核清 → 待补证。

### 维度三：利润与成本

**要回答的问题**：广告前毛利是否 ≥30%？广告天花板多高？资金多久回笼？

**必采字段**（逐项核算，成本往高估、销量往低调、利润往保守算）：
- 实收售价、采购成本、包装、头程及关税、佣金、FBA 配送费、入仓仓储、退货损耗。
- 广告前毛利率（对照 2.1 硬门槛）。
- 目标售价 / 市场可比售价 / 降价情景（对照 2.1 压力测算）。
- 保本 ACOS / 目标 ACOS / TACOS（对照 2.2）。
- 单件净利与回款周期（对照 2.1 分档）。

**硬门槛**：广告前毛利率 ≥ 30%；真实成本下无法达到且无法改善 → **淘汰**。

**数据来源**：`get_asin_info`（售价 / FBA 费 / 佣金 / 尺寸重量）、利润测算表模板、FBA 计算器、官方费率表。

**淘汰 / 待补证信号**：核心成本、包装档位等关键费用未核清 → **待补证（阻止测款）**，不得凭估算直接放行或淘汰。

### 维度四：产品差异化与痛点

**要回答的问题**：竞品差评集中在哪些**可验证**的问题？能否改良？能否一句话讲清价值增量？

**判断方法**：必须走「可验证评论分析」流程（见 5.4），从评论原文提取，而非词频总结或 AI 泛泛归纳。

- 差评集中在可改良点（质量 / 材质 / 尺寸适配 / 耐用度）。
- 核心属性：成熟市场有 2–3 个核心属性，选其一切入。
- 差异化方向：功能、设计、颜色、尺寸、数量、包装、套装、质量、人群、场景。
- 价值主张：一句话讲清「比现有产品多解决什么」。

**数据来源**：`get_category_review_analysis`、`get_asin_info`、评论原文抽样、Shulex VOC 分析。

**淘汰 / 待补证信号**：纯复制爆款无差异 → 淘汰；无评论原文支撑的「痛点」→ 待补证。

### 维度五：合规与适用性

**要回答的问题**：产品是否落入受限/禁售范围？是否侵权？需要什么认证？

本维度**不写「带电都需 UN38.3 / UL4200A / CE」这种并列写法**，而是走「产品适用性核查」（见 9.2）：目标市场 → 产品用途/年龄 → 材料与结构 → 适用规则 → 所需证明 → 费用和周期 → 未解决事项。

**绝对禁区**：知名 IP 衍生（迪士尼 / 漫威等）、仿大牌外观或 Logo、未授权印花——投诉即下架，屡犯封号冻结资金。

**专利判断**：不能写成「产品有专利就不能做」或「查不到就无冲突」。必须区分**权利类型（发明 / 实用新型 / 外观）、有效状态、具体保护范围**，再做结论；正式决策不能仅凭外观相似或关键词搜索作法律结论。

**查询路径**：USPTO、WIPO 外观设计数据库、Google Patents、PatentGuru，多换关键词交叉查询。

**淘汰 / 待补证信号**：确认侵权或落入禁售 → 淘汰；权利状态 / 认证要求未核清 → 待补证。**受限类目但可满足要求 ≠ 禁售**，不自动淘汰。

### 维度六：供应链与运营可行性

**要回答的问题**：能不能拿到货、发得走、跑得动？真实配送费与资金要求是多少？

**必采字段**：
- 供应商数量与小批量起订能力。
- 实际 FBA 配送费（**按尺寸、重量、售价档计算，不只看重量或长度**）。
- 损坏率、退货率对资金的要求。
- 头程 Lead Time（海运约 45–70 天，空运约 25–40 天）。

**首单规模**：不再统一「200–1,000 件」或「绿灯发 300–500 件」，改为**根据可承受亏损、到岸成本、预期日销、补货时间**四要素计算（见 6）。

**淘汰 / 待补证信号**：供应商唯一不可控、超大件/易碎/危化且无法化解 → 淘汰；配送费/损坏率数据缺失 → 待补证。

## 四、量化评分模型（仅用于排序）

六维各打 1–5 分，满分 30 分。**必须补齐 2 分与 4 分的标准，且标注证据可信度**，避免 22 分与 21 分仅凭主观印象区分。

**评分前置原则**：**先过硬门槛（安全、毛利、侵权），再谈打分**。未过硬门槛的，不进入排序；未知项不硬打分（标「待补证」，不强行给低分）。

| 维度 | 5 分（优） | 4 分（良） | 3 分（中） | 2 分（差） | 1 分（红灯） |
|------|-----------|-----------|-----------|-----------|-------------|
| 需求 | 搜索量高、多词稳定出单、趋势上行（A 级证据） | 需求稳定，趋势平稳 | 需求一般 | 需求偏弱或高度依赖单一词 | 单爆款垄断 / 搜索持续暴跌 |
| 竞争 | 评论少、集中度低、有真实新品、CPC 可承受 | 集中度中等、有切入缺口 | 竞争中等 | 偏红海、头部集中 | 大牌霸榜 / 首页均千评且无缺口 |
| 利润 | 毛利 ≥30% 且余量充足、降价 20% 仍达标 | 毛利 ≥30% 且余量尚可 | 毛利 ≥30% 但余量薄 | 毛利 25–30%（未达硬门槛） | 毛利 <25% 且无法改善 |
| 差异化 | 痛点经评论原文证实、可改良、有增量 | 有明确差异空间 | 差异一般 | 同质化明显 | 纯复制爆款 |
| 合规 | 无 IP / 认证障碍（已核实） | 低风险 | 需一般认证（周期可接受） | 受限类目但可满足要求 | 确认侵权 / 禁售 |
| 供应链 | 轻小、耐运、供应商多、配送费低 | 常规 | 略复杂 | 偏大件 / 单一供应商 | 超大 / 易碎 / 危化且不可化解 |

**评分用途与边界**：
- 评分只回答「候选之间的相对优先级」，**不决定采购**。
- **利润维度评分前先过硬门槛**：毛利 <30% 直接进入淘汰 / 待补证，不参与排序；达标后再按「利润余量 + 降价压力承受能力」比较高低。
- **合规维度的「受限类目」不再算 1 分红灯**：受限但可满足要求 ≠ 禁售；未知项不硬打分。
- 任一维度为 1 分时，须确认其对应的是否为硬门槛或确认侵权；若是 → 淘汰，若不是 → 记为风险项。
- 每项分数旁标注该维度证据可信度（A/B/C）。

## 五、专项调研表

### 5.1 变体调研表（单独成表）

变体必须单独成表，不能只记录「变体数」。

**必采字段**：父 ASIN、子 ASIN、变体主题、颜色、尺寸、单包数量、配件组成、实际售价、优惠、评分口径、购买提示 / 估销、库存状态、采集日期。

**三条硬规则**：
1. 同一父体下的多个颜色**不能当作多个独立竞争品牌**来统计品牌集中度。
2. 父体销量**不能平均分配给各子体**（各子体销量需分别估销）。
3. 比较单价时，要区分**散装结、成品插签、纸卡插签、混合套装**等产品形态，不能只看「件数」。

**示例提示**：若我方产品为「24 个长尾结 + 26 个成品插签」，不能只跟竞品比「50 件 vs 30 件」，还要比较**用途与成品配置**的差异。

### 5.2 新品机会判断（真实新品 vs 挂靠子体）

「Top100 里新品很多」不能自动解释为「新品容易成功」，也可能只是上新频繁。必须区分「真实从零进入市场的新品牌」与「成熟父体下新增子体」。

**必采字段**：
- 子 ASIN 首次可见时间。
- 父体历史及变体合并情况。
- 评分数属于当前子体，还是多个变体共享。
- 最近 30 / 90 天销量、价格与评分增长。
- 是否依赖大幅折扣、持续广告或原品牌流量。
- 低评链接能否**连续成交**，而非短期冲量。

**更可信的机会证据**：多个独立品牌的低评链接，能以正常价格持续成交。

### 5.3 关键词与需求研究规则（每个产品至少输出）

| 模块 | 必须包含 |
|------|---------|
| 核心词 | ≥5 个，注明购买意图与产品相关性 |
| Amazon 需求 | 搜索量、统计周期、来源；不能把 ABA 排名当搜索量 |
| 趋势 | 美国地区，近 5 年 / 12 个月 / 90 天 |
| 季节性 | 峰值月份、淡季长度、是否逐年重复 |
| 流量竞争 | 点击 / 转化集中度，自然位与广告位分开 |
| 广告可行性 | CPC 来源、预期 CVR、可承受 CPC |
| 数据不足 | 明确标记未取得，不能推断成「没有需求」 |

**关键词聚类口径（新增）**：关键词必须**按购买意图聚类**（同一购买意图的词归为一组），**不直接把各词搜索量相加当作独立买家数**——同一买家会用多个词，直接相加会重复计算需求。

**Google Trends 使用规则**：区分「广泛的审美趋势」与「具体产品的购买需求」。例如「bow cake」的热度，不能直接当作「黑色缎带插签」的销量依据。

### 5.4 评论分析（升级为可验证的产品问题）

评论分析从「词频总结」升级为「可验证的产品问题」，按以下顺序逐条记录：

> **评论原文 → 使用场景 → 具体问题 → 涉及变体 → 样本出现次数 → 改进方式 → 增加成本 → 验证方法**

**统计口径要求**：
- 分开统计「评分数量」与「有文字的评论数量」。
- 近 12 个月评论与历史评论分开。
- 商品问题 / 物流问题 / 使用误解分开统计。
- **好评也要研究**：明确哪些体验不能在降成本时破坏。
- 差评样本中的「出现比例」**不能叫产品缺陷率**。
- **没有评论原文，就不能把 AI 归纳写成已证实的痛点**。
- 「留评率」慎用：累计评价数 ÷ 当前月销量**不是有效留评率**，只能作粗略参考。

## 六、试销规则（可填写数字模板）

试销不再统一「7–14 天 + CTR >0.4% / CVR >12% / ACOS <35%」三个固定指标。**每次测款前，必须把下面表格填成具体数字**，缺一不可：

| 必填项 | 填写内容（示例） |
|--------|----------------|
| 预算上限 | $____（本次测款最多投入） |
| 最大亏损 | $____（可承受亏损，触发即停） |
| 观察期限 | ____ 天（观察节点，非判决期限） |
| 有效点击要求 | ≥____ 次（并注明广告类型 / 位置） |
| 有效订单要求 | ≥____ 单（并注明样本量与流量来源） |
| 停止条件 | 例如：亏损达 $X / 点击 Y 次仍 0 单 / 退货率 >Z% → 停 |
| 补货条件 | 例如：毛利达标、退货 <X%、日销稳定 Y 天 → 触发放量评估 |

**指标判断口径**：
- **CTR**：分广告类型（SP / SB / SD）、广告位（首页首位 vs 商品页）、关键词相关性分别比较。
- **CVR**：分售价、流量来源及订单样本量判断，样本太少不判。
- **ACOS**：由该产品毛利倒推（对照 2.2），**不固定 35%**。
- **7–14 天**：是观察节点，**不是成功 / 失败的判决期限**。

**首单与放量数量**：由「可承受亏损 + 到岸成本 + 预期日销 + 补货时间」四要素计算，不再用固定「200–1,000 件」或「300–500 件」。达到放量条件后，再确认补货周期与现金需求。

## 九、附录

### 9.1 费用核实方法（取消固定速查数字）

**不采用固定费用速查数字作为测算依据**，改为每次测算记录：

- 官方来源（费率表 URL / 帮助页面）。
- 适用日期（费率随 1/15、10/15 及旺季调整，注意 2026 旺季口径）。
- 类目、售价档、包装尺寸档、重量档及附加费。
- FBA 计算器的费用预览结果。

**需逐项核实的费用**：销售佣金、FBA 配送费、月度仓储费、库龄附加费、退货处理费、移除/弃置费。

**退货费正确规则**（修正旧版错误）：亚马逊通常**退还相应销售佣金**，但**扣留退款管理费**，金额为 **$5 或相关佣金的 20%，取较低者**。例如佣金 $1.50，对应退款管理费 $0.30，而不是「仅退 $0.30」。来源：sellercentral.amazon.com 退款费用帮助页。

### 9.2 产品适用性核查（重写合规）

按以下顺序逐项核查，**不写「带电都需 UN38.3 / UL4200A / CE」这类并列**：

> **目标市场 → 产品用途 / 年龄 → 材料与结构 → 适用规则 → 所需证明 → 费用和周期 → 未解决事项**

**关键澄清**：
- **UL 4200A** 对应的是「含有或设计使用纽扣 / 硬币电池的相关消费品」，**不是所有带电产品的通用要求**。
- **UN38.3** 是锂电池运输安全测试，仅针对含锂电池产品。
- **儿童产品**需根据预期年龄与适用安全规则判断测试与 CPC 要求（CPSC）。
- **专利**：区分权利类型（发明 / 实用新型 / 外观）、有效状态、保护范围，正式决策不得仅凭外观相似或关键词搜索作法律结论。

### 9.3 反倾销 / 禁售红线

美国对华反倾销重点：钢钉、钢管、铸铁件、金属硅、重锻造手动工具、蜂蜜、木制卧室家具、彩电、自行车等。带电 / 纯液体 / 带磁 / 食品 / 有安全隐患产品，先做 9.2 适用性核查与 2.5 安全门槛核查再定。
