# 美国站安全与合规核查

合规不是一份清单，是一个判断链。**先判断产品是否落入某条规则的适用范围，再谈需要什么证书**——把"带电都需 UL4200A / CE"这类并列写法当规则用，会既漏检又过度检测。

## 核查顺序（固定）

```
目标市场 → 产品用途与预期年龄 → 材料与结构 → 适用规则 → 所需证明 → 费用与周期 → 未解决事项
```

每一步都要留下记录。跳到最后一步直接问"要什么认证"，必然出错。

## 第一步：判断是否属于儿童产品

这是最关键的岔路口。判断依据是**制造商声明的预期用途**，以及包装、营销、年龄标识所指向的人群，不是产品看起来像不像玩具。

- **面向 12 岁及以下** → 适用 ASTM F963（玩具安全）+ CPSIA + CPC 证书 + 溯源标签
- **面向 13 岁以上或成人** → 一般不适用玩具规则，但仍需符合 CPSIA 中对儿童产品的定义边界、以及一般消费品安全要求
- **模糊地带**（如派对装饰、蛋糕装饰、礼品）→ 若外观、包装、营销卖点明显吸引儿童，或使用场景是儿童派对，**监管与平台都会按儿童产品处理**。不要靠"listing 写 adult use"规避。

## 第二步：适用规则

### ASTM F963-23 与 16 CFR Part 1250

- ASTM F963-23 是玩具安全标准，2024-04-20 起通过 **16 CFR Part 1250** 成为强制性联邦规则，适用于设计或意图供 12 岁及以下儿童使用的产品。
- 主要测试项：机械物理性能（尖点、锐边、小零件、绳带长度）、易燃性、重金属迁移（可触及基材与涂层）、填充物清洁度。
- 第三方实验室测试 + CPC 证书是强制要求。

### CPSIA

| 项目 | 限值 |
|---|---|
| 基材总铅 | ≤ 100 ppm |
| 涂层总铅 | ≤ 90 ppm |
| 邻苯二甲酸酯（8P） | 各 ≤ 0.1%（可入口部件与儿童护理品） |
| 小零件 | 3 岁以下禁止存在可完全放入小零件圆筒的部件 |

### 小零件测试（16 CFR Part 1501）

- 使用**小零件圆筒**（直径 31.7 mm、深度 57.1 mm，开口端内径约 16 mm 的判定口径）。
- 适用于 **36 个月以下**儿童产品：任何可脱落、可分离的部件不得完全容入圆筒。
- **高风险形态**：树脂小件、泡沫球、珠球、宝石贴片、可拆卸装饰件。这类产品做低龄线时必须做脱落测试，或直接在设计上做大尺寸、一体成型。

### CPC 证书（Children's Product Certificate）

- 由制造商或进口商自行出具，**基于第三方实验室测试结果**，不是实验室出具。
- 必须包含：产品标识、适用规则清单、进口商/制造商信息、测试机构信息、生产日期与地点、测试日期与地点。
- 亚马逊要求上传 CPC 并通过合规文件验证，文件不合规会直接下架。

### 溯源标签（Tracking Label）

儿童产品必须有永久性溯源标识，包含制造商名称、生产地点、生产日期、批次信息。贴在包装上不够，需在产品和包装上同时可查。

### CPSC eFiling（2026-07-08 起）

美国 ACE 报关系统要求提交 CPSC 证书数据（eFiling）。2026-07-08 起，受 CPSC 规则约束的进口货物在清关时需以电子方式提交合规证书数据，纸质 CPC 不能替代。这会影响头程报关流程与货代配合方式，需提前确认货代是否支持。

### 食品接触（FDA）

蛋糕装饰、餐具、食品容器等与食物直接接触的产品，需符合 FDA 21 CFR 相关条款（如 21 CFR 175/176/177 间接食品添加剂、21 CFR 178 等）。要求：
- 食品级材质声明（如 PP、食品级硅胶、食品级色素）
- 部分材质需 FDA 食品接触声明或第三方迁移测试
- 若产品标注"可食用"，则同时受食品法规约束，门槛大幅提高

### 电池相关（按类型对应，不通用）

| 规则 | 适用对象 |
|---|---|
| **UL 4200A** | 含有或设计使用**纽扣/硬币电池**的消费品。不是所有带电产品的通用要求 |
| **UN38.3** | 含**锂电池**产品的运输安全测试 |
| **16 CFR Part 1263** | 纽扣电池或硬币电池消费品的安全标准 |

### 其他常见

- **CPSA Section 15(b)**：已知产品危害需向 CPSC 报告
- **FHSA**：危险物质标签
- **加州 Prop 65**：化学暴露警告标签（铅、邻苯、BPA 等）
- **磁性产品**：ASTM F963 磁体要求，高磁通量磁体对儿童风险极高

## 第三步：知识产权

不能写成"有专利就不能做"或"查不到就无冲突"。必须区分：

- **权利类型**：发明专利 / 实用新型 / 外观设计（design patent）
- **有效状态**：有效、过期、放弃、审中
- **保护范围**：权利要求覆盖什么，你的产品是否落入

**正式决策不能仅凭外观相似或关键词搜索作法律结论**，需要专业检索或律师意见。

查询路径：

- USPTO Patent Full-Text Search: http://patft.uspto.gov
- USPTO Trademark Search: https://tmsearch.uspto.gov
- Google Patents: https://patents.google.com
- WIPO 外观设计库: https://www3.wipo.int/designdb/en/index.jsp
- PatentGuru: https://www.patentguru.com

**绝对禁区**：知名 IP 衍生（迪士尼、漫威、皮克斯、宝可梦、热门游戏/动漫角色）、仿大牌外观或 Logo、未授权印花。投诉即下架，屡犯封号冻结资金。**"通用奇幻龙"可以做，"《驯龙高手》无牙仔"不能做**——判断标准是是否指向特定 IP 形象。

## 第四步：反倾销与禁售

美国对华反倾销重点品类：钢钉、钢管、铸铁件、金属硅、重锻造手动工具、蜂蜜、木制卧室家具、彩电、自行车等。

带电、纯液体、带磁、食品、有安全隐患的产品，先做适用性核查与安全门槛核查，再定是否进入。

## 输出要求

合规结论落到三档，不得写"应该没问题"：

| 结论 | 含义 | 后续 |
|---|---|---|
| **通过** | 适用规则已明确，所需证明已取得或可取得，无未解决事项 | 可进入下一步 |
| **待补证** | 适用范围未核清、证明未取得、材料声明缺失 | 补齐前不得测款 |
| **淘汰** | 确认落入禁售、确认侵权、存在无法通过设计改善的严重伤害风险 | 放弃 |

## 安全门槛的判断标准（独立于合规）

合规是"有没有证"，安全是"会不会伤人"。两者都要过。

**判断标准**：在**预期使用 + 合理可预见的误用**下，是否存在未解决的严重伤害风险。

**处理规则**：
- 未核清（材料安全、结构、小件脱落风险不明）→ **待补证**，不得测款
- 已确认存在严重伤害风险且无法通过设计改善 → **淘汰**

**执行原则**：安全结论不需要等到出现差评或事故才考虑。低评价、销量好、毛利达标，都不能抵消"直接放在奶油上可能被误食"这类未解决风险。

**典型案例**：亚克力蛋糕宝石装饰件，销量好、毛利达标、评分不低，但小尺寸装饰件直接放在奶油上，儿童派对场景下存在误食风险且未解决——这类产品不应被规则放行。正确处理是"待补证"（核实材质与尺寸、加"not edible / remove before serving"标注、或改成大尺寸一体件），而不是因为数据好看就放过。
