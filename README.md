# Amazon US Product Selection

**一套可执行的亚马逊美国站选品判断方法论。**
把"我觉得这个能做"变成"有依据地判断能不能做，以及还缺什么证据"。

## 它解决的问题

选品失败很少是因为选错了品类，通常是因为**用错的成本结构算了一个看起来很好的机会**。

一个真实的例子：某类目头部产品月销 15,419 单、评分 4.7、品牌占类目 42.5% 销量、BSR 第一。所有直觉指标都在说"可以做"。但把真实 FBA 费代进去——售价 $6.99，FBA $3.51，佣金 15%，广告前毛利只剩 **11.5%**。它不是在赚钱，是在靠规模和现金流周转。新进入者没有它的采购成本，照抄价格等于照抄亏损。

反过来也常见：首页评论都是几千条，直接放弃。但仔细看会发现头部链接正在亏损换量，评论区骂的是同一个可以被设计解决的缺陷。

**这类判断需要的不是更多数据，是正确的方法。**

## 三个能力

### 1. 判断单个产品能不能做

给出竞品 ASIN，输出四状态结论（淘汰 / 待补证 / 允许测款 / 允许放量）与逐条依据。不做"建议谨慎考虑"这类无法执行的判断。

### 2. 扫类目，找替代方向

当原方向被否掉时，不是随便再挑一个品，而是**换一个价格结构**。下钻细分节点、逐个算价格下限、用新品存活数据验证，找出真正能撑住毛利的方向。

### 3. 排主题优先级

产品方向已定时，用六个可批量计算的指标横向比较候选主题：需求体量、供给密度、供需比、评论壁垒、价格可行性、广告依赖。

---

## 三条铁律

这三条是整个方法论的骨架。违反任何一条，后面的分析全部作废。

**先过硬门槛，再谈打分。**
安全、广告前毛利 ≥30%、侵权。未过的直接进"淘汰"或"待补证"，不参与排序。六维评分只回答"在能做的候选里先做哪个"，永远不能把不达标的品抬进去。

**缺失不等于没有风险，也不等于没有需求。**
数据没拿到就标"待补证"。同时区分关键缺失（安全、核心成本、包装档位、权利状态）与辅助缺失（5 年趋势、精确销量）——只有关键缺失才阻止测款。

**任何竞品数据都不能直接触发放量。**
允许放量必须由自己的真实经营数据触发。竞品销量再高、工具估算再好，都只能支撑"允许测款"。

## 单独用计算器

不需要 Agent 也能用。核心只有一个公式：

```
最低可售价 = (FBA 配送费 + 落地成本 + 其他变动费用) ÷ 0.55
```

0.55 = 1 − 15% 佣金 − 30% 目标毛利。

```bash
python scripts/margin_calc.py --price 9.99 11.99 12.99 14.99 --fba 4.36 --landed 1.80
```

```
     售价      佣金      变动成本      广告前毛利      毛利率    降价10%后      广告后
  $9.99    $1.50      $7.36       $1.13     11.3%       3.1%     $1.13  << 未达门槛
 $11.99    $1.80      $7.36       $2.83     23.6%      16.8%     $2.83  << 未达门槛
 $12.99    $1.95      $7.36       $3.68     28.3%      22.0%     $3.68  << 未达门槛
 $14.99    $2.25      $7.36       $5.38     35.9%      30.4%     $5.38

最低可售价（30% 毛利）：$13.38
```

**这条公式最能说明的问题**：如果类目的销量加权成交价低于这个数，那个价格带里没人能赚钱。不是竞争激烈，是结构性亏损。

## 一个反直觉的结论

同一价格带下，**包装厚度比产品设计更值钱**。

| 产品 | 售价 | 包装厚 | FBA | FBA 占售价 | 广告前毛利 |
|---|---|---|---|---|---|
| 48 件扁平纸卡 | $7.99 | 0.5 cm | $2.71 | 34% | **31%** |
| 12 件立体蜡烛组 | $8.98 | 4.8 cm | $4.21 | 47% | **8%** |

售价差 $0.99，配送费差 $1.50，毛利差 23 个百分点。

由此得出的设计原则：优先做可平铺、可嵌套的形态，厚度控制在 1 cm 内；能用"零件 + 组装"就不要"成品发货"；数量做多不一定值钱（FBA 按尺寸重量算，不按件数算），但能撑住价格感知。

## 数据源

方法论不绑定特定工具。内置的工具映射基于类目洞察类 MCP（如西柚找词 xiyou-insight），也支持用亚马逊前台数据 + 店铺页抓取替代——但那样销量与流量只能标 B 级（工具估算）。

**仓库不含任何 API 密钥。** 自行接入数据源时，凭证请放在本地环境变量或 Agent 的 MCP 配置里，不要提交进仓库。

## 适用 / 不适用

**适用**：竞品调研、类目机会扫描、主题选题、利润与价格门槛核算、美国站合规核查

**不适用**：纯关键词挖掘、Listing 撰写、广告投放优化、供应商谈判

## 方法论版本

当前 **V2.1**。相比早期版本的关键修正：

- 六维框架降级为"调研提纲与排序工具"，不作为采购判决器
- 增加产品安全硬门槛（预期使用 + 合理可预见误用下的严重伤害风险）
- 利润口径统一为三层，硬门槛提到广告前毛利 ≥30%
- 取消"一套阈值适用所有类目"，改为 A/B/C 选品池分层
- 区分关键缺失与辅助缺失
- 合规从"认证清单"改为"产品适用性核查"（如 UL 4200A 仅对应纽扣/硬币电池产品，不是所有带电产品）
- 修正退货费规则（退还佣金，扣留 $5 或佣金 20% 取低者）
- 试销规则从固定指标改为可填写数字的模板
